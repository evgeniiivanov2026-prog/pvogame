# PVOGame.ru — Защита Helios Station

Тактическая sci-fi игра о защите вымышленной станции Helios от волн автономных объектов.

## 📖 О проекте

**PVOGame.ru** — браузерная 2D-игра в жанре tower defense с элементами тактического менеджмента. Игрок защищает гражданскую инфраструктуру от абстрактных автономных объектов, используя различные защитные модули.

**Важно:** Это полностью вымышленная игра. Все названия, объекты и механики не имеют отношения к реальным вооружениям, странам или военным операциям.

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Сборка для продакшена
npm run build
```

После сборки откройте `dist/index.html` в браузере.

## 🎮 Управление

### Основные действия
- **Мышь** — выбор модулей, размещение, выбор целей
- **ЛКМ** — разместить модуль / выбрать объект
- **ПКМ** — отменить размещение
- **Space** — пауза/продолжение
- **1** — скорость ×1
- **2** — скорость ×2
- **Esc** — отменить размещение / закрыть окно / закрыть админку
- **R** — перезапуск (после Game Over)

### Восстановление контроля
- **Q** — Анализ (25 Focus, КД 32с)
- **W** — Приоритет канала (18 Focus, КД 25с)
- **E** — Сетевое дыхание (15 Focus, КД 20с)

### Админ-панель
- **Ctrl+Shift+P** — открыть/закрыть панель управления

## 🎯 Игровые механики

### Ресурсы
- **Integrity** — прочность станции (100/100)
- **Credits** — валюта для строительства
- **Energy** — энергия для модулей
- **Focus** — концентрация оператора (0-100)
- **Stress** — уровень стресса (0-100)
- **Composure** — спокойствие оператора (0-100)
- **Score** — очки

### Цикл игры
1. Подготовка → размещение модулей
2. Волна → объекты движутся к станции
3. Нейтрализация → уничтожение или пропуск
4. Награды → кредиты и очки
5. Выбор перка → улучшение на следующий уровень
6. Повтор

### Сложность
5 уровней сложности:
- **Спокойный** — для новичков
- **Стандартный** — базовый баланс
- **Высокая нагрузка** — повышенная сложность
- **Экспертный** — для опытных игроков
- **Пользовательский** — настройка параметров

Смена сложности применяется со следующей волны.

### Кампания
- 12 волн с нарастающей сложностью
- Бесконечный режим после прохождения
- Сохранение рекорда в localStorage

## 🛡️ Защитные модули

### Sentinel Sensor (80¢)
Обнаруживает цели в радиусе действия. Пассивный модуль.
- Улучшения: +40/+80 дальность

### Signal Veil (120¢)
Замедляет объекты в зоне действия.
- Улучшения: +10%/+20% замедление

### Arc Interceptor (150¢)
Поражает одну цель за раз. Средняя дальность.
- Улучшения: +10/+25 урон, -200мс кулдаун

### Pulse Array (200¢)
Поражает несколько целей в области.
- Улучшения: +1/+2 цели, +20 радиус

### Guardian Node (100¢)
Быстрая защита ближнего рубежа.
- Улучшения: +7/+17 урон, -100/-200мс кулдаун

### Приоритеты атаки
- Ближайшая к станции
- Самая быстрая
- Самая прочная
- Высшая угроза
- Слабейшая
- Дольше в зоне

## 🧠 Stress и Focus

### Stress (0-100)
Растёт от:
- Близких объектов
- Низкой Integrity/Energy
- Негативных событий

Снижается от:
- Спокойной обстановки
- Высокой Energy
- Конца волны

### Focus (0-100)
Регенерация:
- +0.7/с при stress <35
- +0.35/с при 35-59
- +0.1/с при 60-74
- 0/с при ≥75

### Composure (0-100)
Снижается при высоком Stress.
Восстанавливается в спокойной обстановке.

### Panic Levels
- **Calm** (<25) — синий
- **Alert** (25-44) — жёлтый
- **Tense** (45-64) — оранжевый
- **Critical** (65-79) — красный
- **Overload** (≥80) — тёмно-красный

## 🎨 Процедурная местность

Игра генерирует уникальную местность для каждой сессии:

### Архетипы регионов
- **auroraRidges** — светящиеся хребты
- **quietBasins** — спокойные низины
- **fracturedPlateau** — разломанное плато
- **crystalVeins** — кристаллические жилы
- **signalTide** — сигнальные приливы
- **shatteredArc** — разбитые арки
- **softOrbit** — мягкие орбиты

### Препятствия (декоративные)
- prismCluster — призматические кластеры
- echoPillar — эхо-колонны
- fracturedShard — разбитые осколки
- lumenArch — световые арки
- driftStone — дрейфующие камни
- signalReef — сигнальные рифы

Генерация через seeded RNG с value noise / fbm.

## ⚙️ Настройка баланса

Все параметры в `src/gameEngine.ts`, объект `CONFIG`:

```typescript
CONFIG = {
  STATION: { maxIntegrity: 100 },
  ENEMIES: { scout: { hp, speed, damage, ... } },
  MODULES: { sentinel: { cost, range, damage, ... } },
  WAVES: [...],
  PERKS: [...],
  RECOVERY: {...},
  TERRAIN: { archetypes, seed },
  OBSTACLES: { types, density },
  DIFFICULTIES: [...]
}
```
